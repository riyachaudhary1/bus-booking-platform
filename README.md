# BusBooker 🚌

A comprehensive full-stack web application for bus booking and travel community management.

## ✨ Features

### 1. Community System
- Create and share travel experiences
- Comment on posts
- Like/Unlike functionality
- Content moderation
- User verification badges

### 2. Real-time Notifications
- Toast notifications
- Notification center
- Customizable preferences
- Event-triggered alerts

### 3. Route Planning
- Advanced search functionality
- Filter & sort options
- Traffic level indicators
- Seat availability
- Operator information

### 4. Multi-language Support
- English, Hindi, Spanish
- Dynamic switching
- localStorage persistence

### 5. Dark Mode
- Light/Dark theme toggle
- Smooth transitions
- CSS variables

### 6. Rating & Reviews
- 5-star rating system
- Review CRUD operations
- Rating analytics
- Moderation features

## 🛠️ Tech Stack

- **Frontend:** React 18, Context API, CSS3
- **State Management:** Context API with Hooks
- **Styling:** CSS3 with CSS Variables
- **Storage:** localStorage
- **Deployment:** Netlify

## 🚀 Getting Started
```bash
# Clone repository
git clone https://github.com/riyachaudhary1/bus-booking-platform.git

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```
